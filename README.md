CODELEARN LANDING PAGE

English

CodeLearn is a professional, responsive landing page for a programming company. It is built using plain HTML, CSS, and JavaScript, with no frameworks or external images.

Features:
- Persian, right-to-left layout
- Responsive design for mobile, tablet, and desktop
- Hero section with a decorative code window
- Technology, services, portfolio, About Us, FAQ, and contact sections
- Header background change on scroll
- Toggleable mobile navigation menu
- Expandable FAQ items
- Scroll-triggered reveal animations
- CSS transitions and animations

Project files:
- index.html: Page structure and content
- style.css: Styling, responsive layout, and animations
- script.js: Navigation menu, FAQ accordions, and scroll effects

To run the project, open the project folder in Visual Studio Code, install the Live Server extension if needed, then right-click index.html and select “Open with Live Server.” No package installation or build tools are required.


صفحه فرود CODELEARN

فارسی

CodeLearn یک صفحه فرود حرفه‌ای و واکنش‌گرا برای یک شرکت برنامه‌نویسی است. این پروژه با HTML، CSS و JavaScript ساده ساخته شده و از فریم‌ورک یا تصویر خارجی استفاده نمی‌کند.

امکانات:
- محتوای فارسی با چیدمان راست‌چین
- طراحی واکنش‌گرا برای موبایل، تبلت و دسکتاپ
- بخش معرفی همراه با پنجره کد تزئینی
- بخش‌های فناوری‌ها، خدمات، نمونه‌کارها، درباره ما، پرسش‌های متداول و تماس
- تغییر پس‌زمینه هدر هنگام اسکرول
- منوی باز و بسته‌شونده در موبایل
- پرسش‌های متداول آکاردئونی
- نمایش تدریجی عناصر هنگام اسکرول
- انیمیشن‌ها و ترنزیشن‌های CSS

فایل‌های پروژه:
- index.html: ساختار و محتوای صفحه
- style.css: استایل‌ها، طراحی واکنش‌گرا و انیمیشن‌ها
- script.js: منوی موبایل، آکاردئون پرسش‌های متداول و افکت‌های اسکرول

برای اجرای پروژه، پوشه آن را در Visual Studio Code باز کنید. در صورت نیاز افزونه Live Server را نصب کنید، سپس روی فایل index.html راست‌کلیک کرده و گزینه «Open with Live Server» را انتخاب کنید. نیازی به نصب پکیج یا ابزار build نیست.
